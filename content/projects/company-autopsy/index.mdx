## The problem

Most companies know AI agents could help, but not where to start, and a first call usually spends half an hour just mapping what the business does. I wanted something a visitor can try in under a minute that does that mapping for their own company and ends with one concrete pilot worth talking about.

## Decisions & tradeoffs

- **A safe fetch, because the input is someone else's URL.** Only http(s) on ports 80 and 443. DNS is resolved once and every IP is checked, then the connection goes to that exact IP, so a DNS answer cannot swap in a private address later. Every redirect is checked again, pages are capped in size and time, and robots.txt is respected.
- **Website text is treated as untrusted data.** It goes to the model inside a fenced block with a system prompt that says to ignore any instructions in it, and the answer must match a strict schema or it is rejected.
- **A fallback chain on a free tier.** Gemini Flash-Lite first, then Flash, with per-IP rate limits and a daily cap. When the quota runs out, visitors see a clearly labelled sample report instead of an error.
- **No database.** A report is compressed into the share link and signed with HMAC, so links can't be edited and there is nothing to store or leak. Each shared report gets its own preview image.
- **Progress streams live.** The page shows each step (reading pages, analysing) as it happens, so a cold start or a slow site doesn't look like a hang.

## What broke

- **The SSRF guard blocked the sandbox it was tested in.** The test machine's DNS resolves every host to a reserved range, which the guard correctly refused. A development-only allow list fixed testing without loosening production.
- **The share preview showed a missing-glyph box.** The image renderer's font had no "✚", so the card logo rendered as a blank box until I swapped in a plain "+".

## What's next

Measuring how often the suggested pilot matches what a person would pick after a real call, and a shared rate limit store so the limits hold across more than one server.
